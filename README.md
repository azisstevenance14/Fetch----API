project sederhana ini dibuat sebagai bagian dari pembelajaran fundamental JavaScript Lanjutan dengan pendekatan Learn by Doing. Focus utama materi hari ini adalah memahami konsep Asynchronous JavaScript, penggunaan Fetch API, serta penanganan data lokal secara non-blocking.

🎯 Target & Tujuan Pembelajaran

Memahami Konsep Asynchronous: Mengerti perbedaan alur kerja Synchronous (blocking) dan Asynchronous (non-blocking).

Fetch API & Async/Await: Mengambil data dari file JSON lokal secara modern tanpa menggunakan library external.

Error Handling: Mengimplementasikan blok try...catch, validasi response.ok, dan penanganan error manual menggunakan new Error().

DOM Manipulation & Iteration: Mengolah data Array dari JSON menggunakan metode .forEach() untuk ditampilkan ke dalam elemen HTML secara dinamis.
